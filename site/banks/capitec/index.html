Capitec Smart ID branches, booking and walk-ins

Checked against the Department of Home Affairs and Capitec on 26 October 2026. Sources are linked next to each fact.

In short. Capitec Smart ID branches, booking and walk-ins: the client rule, the fee, and the branch list from the Department of Home Affairs locator.

373 Digital Partnership branches on 26 October 2026. Walk-in: Yes. DHA says Capitec allows walk-ins without an appointment [source]. Booking: how this differs from a Home Affairs appointment.

  • Model: DHA Digital Partnership [source]. Walk-ins without appointment [source].
  • Services: Smart ID replacements only (lost, stolen, damaged, or green ID book to Smart ID). First-time IDs not available in branch [source].
  • Account: you pay using a Capitec account; if you have none, the branch can help you open one, and it must be active with a positive balance [source].
  • Documents: none needed; bring green ID book if opening an account [source].
  • Cost: R150 total (R140 DHA fee plus R10 service fee) [source].
  • Passports: not stated by source as currently available at Capitec branches. A 2025 gov.za statement announced Smart ID and passports at Capitec, open to non-clients [source]; Capitec's current page requires a Capitec account [source].
  • Capitec branch locator has a Smart ID filter [source].

Replacing a lost or stolen card: Replacing a lost or stolen Smart ID. A first Smart ID at 16: First Smart ID at 16. Collection: Smart ID collection booking. The green ID book deadline: Green ID book deadline. A passport: Applying for a passport. A forename or surname: Name or surname change. A date of birth or recorded sex: Date of birth or gender.
