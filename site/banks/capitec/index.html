Capitec: Smart ID and passport at branches

In short. Capitec Smart ID and passport branch service: walk-in or booking, client requirement, fees and branch list. Sourced from the Department of Home Affairs.

  • Model: DHA Digital Partnership [source]. Walk-ins without appointment [source].
  • Services: Smart ID replacements only (lost, stolen, damaged, or green ID book to Smart ID). First-time IDs not available in branch [source].
  • Account: you pay using a Capitec account; if you have none, the branch can help you open one, and it must be active with a positive balance [source].
  • Documents: none needed; bring green ID book if opening an account [source].
  • Cost: R150 total (R140 DHA fee plus R10 service fee) [source].
  • Passports: not stated by source as currently available at Capitec branches. A 2025 gov.za statement announced Smart ID and passports at Capitec, open to non-clients [source]; Capitec's current page requires a Capitec account [source].
  • Capitec branch locator has a Smart ID filter [source].
